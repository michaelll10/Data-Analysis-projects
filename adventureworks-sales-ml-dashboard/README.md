# 📊 AdventureWorks Sales Analysis & Streamlit Dashboard

## 📌 Project Overview
This project analyzes and visualizes internet sales data from the **AdventureWorksDW2019** database using a **Streamlit** web dashboard.  
It includes a complete data pipeline — from SQL extraction to cleaning, feature engineering, encoding, scaling, and interactive visualization.

**Main Features:**
- Extract data from SQL Server
- Clean & preprocess the dataset
- Feature engineering (Total Paid, Age, Tenure Days, cyclic date encoding)
- Outlier handling and missing value imputation
- Encode categorical variables (One-Hot & Binary Encoding)
- Scale numerical features
- Save cleaned and encoded datasets
- Explore data interactively via Streamlit dashboard

---

## 🛠 Technologies Used
- **Python** – Data processing and visualization
- **Streamlit** – Interactive dashboard
- **SQL Server** – Source database
- **Pandas / NumPy** – Data manipulation
- **Matplotlib / Seaborn / Plotly** – Visualization
- **scikit-learn** – Preprocessing and encoding
- **category_encoders** – Binary encoding
- **pyodbc** – Database connection
